# React Online Shop

A simple and responsive e-commerce web application built with React. This project was created as a practice to master React components, state management, and shopping cart functionality.

## Features

- **Product Catalog:** Browse through a list of available products.
- **Shopping Cart:** Add or remove items from the cart dynamically.
- **Responsive Design:** Works smoothly on different screen sizes.

## Built With

- **React.js** (JavaScript Library)
- **HTML5 & CSS3**
- **Git & GitHub**

## Getting Started

To get a local copy up and running, follow these simple steps:

1. Clone the repository:
```bash
git clone https://github.com/niloofar-sahabi/react-online-shop.git
```
2. Navigate to the project directory:
```bash
cd react-online-shop
```
3. Install dependencies:
```bash
npm install
```
4. Run the development server:
```bash
npm start
```
